# Execution plan: research constitution and workflow

## Purpose

Create the research governance layer for the new stochastic-agent project before implementation begins.

## Scope

Documentation only. No source code, agent framework, model call, trace collection, or UI.

## Work completed

- Define the project objective and initial controlled workload.
- Define the experimental unit and random trajectory object.
- Define the distinction between run, event, campaign, intervention, and analysis.
- Define scientific and engineering non-negotiables.
- Define the specification, plan, test, and validation workflow.
- Define public/private data constraints.

## Review checklist

- [x] Objective is stated in measurable terms.
- [x] Initial workload is controlled synthetic IT incidents.
- [x] Experimental unit is one complete fresh run.
- [x] Nested event independence is explicitly rejected.
- [x] Markov and queueing assumptions require evidence.
- [x] No live model execution is required.
- [x] The next feature is clearly bounded: observable run/event schema.

## Discoveries

This stage establishes governance only. It does not produce empirical evidence.
